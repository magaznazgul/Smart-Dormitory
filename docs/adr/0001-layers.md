# ADR-0001: Жоба архитектурасын төрт қабатқа бөлу

## Мәртебесі

Қабылданды (Accepted).

## Контекст

Smart Dormitory жобасында жатақхана тұрғындарының өтінімдерін басқару, жөндеу жұмыстарын ұйымдастыру, келушілерді тіркеу және хабарландыруларды жариялау функциялары жүзеге асырылады.

Жобаның құрылымы түсінікті, өзгертуге ыңғайлы және тестілеуге қолайлы болуы үшін архитектураны бірнеше қабатқа бөлу қажет.

## Қабылданған шешім

Жобаны төрт қабатқа бөлу туралы шешім қабылданды:

1. **Domain** — негізгі объектілерді, бизнес-модельдерді және Repository интерфейстерін сақтайды.
2. **Service** — жүйенің негізгі бизнес-логикасын орындайды.
3. **Infra** — деректерді сақтау және сыртқы қызметтермен байланыс орнатады.
4. **UI** — пайдаланушымен өзара әрекеттесуді қамтамасыз етеді.

## Тәуелділік бағыты

- UI қабаты Service қабатына тәуелді.
- Service қабаты Domain қабатындағы модельдер мен интерфейстерді пайдаланады.
- Infra қабаты Domain қабатында анықталған Repository интерфейстерін жүзеге асырады.
- Domain қабаты басқа қабаттарға тәуелді емес.

## Қарастырылған баламалар

**1-нұсқа: Монолиттік архитектура**

Барлық кластарды бір пакетте орналастыру. Бұл тәсіл қарапайым болғанымен, жобаны кеңейту мен тестілеуді қиындатады.

**2-нұсқа: Қабатталған архитектура**

Жүйені domain, service, infra және ui қабаттарына бөлу. Бұл тәсіл кодты ұйымдастыруды, тестілеуді және болашақта кеңейтуді жеңілдетеді.

## Қорытынды

Екінші нұсқа таңдалды, себебі ол Smart Dormitory жобасының құрылымын реттеуге және жобалау үлгілерін дұрыс қолдануға мүмкіндік береді.
