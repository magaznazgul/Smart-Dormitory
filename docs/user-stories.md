# Пайдаланушы тарихтары (User Stories)

## US-01. Өтінім жіберу

Тұрғын ретінде мен жатақхана әкімшілігіне өтінім жібергім келеді, себебі өз мәселемді хабарлауым керек.

Қабылдау критерийлері:
- Given тұрғын жүйеге кірген, When өтінім жібергенде, Then өтінім жүйеде сақталуы керек.
- Given өтінім бос, When оны жібергенде, Then жүйе қате туралы хабарлауы керек.

## US-02. Жөндеу жұмыстарына өтінім беру

Тұрғын ретінде мен бөлмедегі ақау туралы хабарлағым келеді, себебі оны жөндетуім керек.

Қабылдау критерийлері:
- Given бөлмеде ақау бар, When тұрғын өтінім жіберсе, Then жөндеу өтінімі жасалуы керек.
- Given өтінім жасалған, When әкімші оны ашса, Then өтінімнің күйі көрсетілуі керек.

## US-03. Өтінім күйін бақылау

Тұрғын ретінде мен өз өтінімімнің күйін көргім келеді.

Қабылдау критерийлері:
- Given өтінім бар, When тұрғын өтінімдер тізімін ашса, Then оның күйі көрсетілуі керек.
- Given өтінім орындалған, When тұрғын оны қараса, Then күйі «Орындалды» болып көрінуі керек.

## US-04. Өтінімді өңдеу

Әкімші ретінде мен тұрғындардың өтінімдерін өңдегім келеді.

Қабылдау критерийлері:
- Given жаңа өтінім бар, When әкімші оны қабылдаса, Then өтінім күйі «Қабылданды» болуы керек.
- Given өтінім қабылданған, When әкімші оны аяқтаса, Then күйі «Орындалды» болуы керек.

## US-05. Келушіні тіркеу

Әкімші ретінде мен жатақханаға келген адамдарды тіркегім келеді.

Қабылдау критерийлері:
- Given келуші туралы ақпарат бар, When әкімші оны тіркесе, Then мәлімет журналға сақталуы керек.
- Given келушінің аты енгізілмеген, When тіркеу орындалса, Then жүйе қате көрсетуі керек.

## US-06. Келушілер журналын қарау

Әкімші ретінде мен келушілер журналын көргім келеді.

Қабылдау критерийлері:
- Given журналда жазбалар бар, When әкімші журналды ашса, Then барлық тіркелген келушілер көрсетілуі керек.
- Given журнал бос, When әкімші оны ашса, Then бос журнал туралы хабарлама шығуы керек.

## US-07. Хабарландыру жариялау

Әкімші ретінде мен тұрғындарға хабарландыру жариялағым келеді.

Қабылдау критерийлері:
- Given хабарландыру мәтіні енгізілген, When әкімші жарияласа, Then хабарландыру жүйеде сақталуы керек.
- Given хабарландыру мәтіні бос, When әкімші жарияласа, Then жүйе қате көрсетуі керек.

## US-08. Хабарландыруларды көру

Тұрғын ретінде мен әкімшілік жариялаған хабарландыруларды көргім келеді.

Қабылдау критерийлері:
- Given хабарландыру жарияланған, When тұрғын хабарландырулар бөлімін ашса, Then хабарландыру көрсетілуі керек.
- Given хабарландыру жоқ, When тұрғын бөлімді ашса, Then сәйкес хабарлама көрсетілуі керек.

## US-09. Өтінім туралы хабарлама алу

Тұрғын ретінде мен өтінімімнің күйі өзгергенде хабарлама алғым келеді.

Қабылдау критерийлері:
- Given өтінім күйі өзгерген, When жүйе өзгерісті тіркесе, Then тұрғынға хабарлама көрсетілуі керек.
- Given өтінім күйі өзгермеген, When жүйе тексерсе, Then жаңа хабарлама жіберілмеуі керек.

## US-10. Өтінімдер тізімін қарау

Әкімші ретінде мен барлық өтінімдерді көргім келеді.

Қабылдау критерийлері:
- Given жүйеде өтінімдер бар, When әкімші тізімді ашса, Then барлық өтінімдер көрсетілуі керек.
- Given өтінімдер жоқ, When әкімші тізімді ашса, Then бос тізім туралы хабарлама шығуы керек.
